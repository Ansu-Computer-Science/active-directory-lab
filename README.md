# Active Directory Lab

## Overview
This project involves building a simulated enterprise network environment using Windows Server Active Directory. The goal is to understand how organizations manage users, computers, and security policies within a corporate network.

## Purpose
Active Directory is widely used in enterprise environments for identity management and access control. This lab replicates a corporate IT infrastructure to gain hands-on experience with domain administration.

## Lab Components
- Windows Server
- Active Directory Domain Services
- Group Policy Management
- Domain user and computer management

## Skills Demonstrated
- Windows Server administration
- Active Directory configuration
- User and group management
- Security policy implementation

## What I Learned
Through this lab I gained practical knowledge of how enterprise networks manage authentication, access control, and centralized administration using Active Directory.
